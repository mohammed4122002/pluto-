# Phase 01 — Technical Implementation & Limitations

## Pipeline

**Remotion 4 + React 19 + SVG**, rendered frame by frame in headless Chromium and encoded with H.264 (CRF 16, yuv420p).

**Why this pipeline:**
- Every frame is a pure function of the frame number, so renders are frame-accurate and repeatable.
- Scenes can be rendered on their own.
- Audio can be added as separate tracks.
- Remotion Studio gives a scrubbable timeline for editing.

No external image or video generation was available in this environment, so **every visual is original artwork drawn in code**:
- vector paths for the character, props, trees and terrain;
- procedurally generated textures (numpy) for fog, paper, brush grain and film grain.

Nothing was generated by an AI image or video model, and no stock assets were used.

### The 2.5D camera (`src/engine/camera.ts`)
- **World:** metres. X right, Y up, Z away from the lens; the ground is Y = 0.
- **Camera:** a real perspective camera (position, focal length in px, vertical lens shift for framing) that never pitches, so verticals stay vertical.
- **Ground:** the ground and the five paths are real ground-plane polygons, clipped at the near plane and projected every frame.
- **Billboards:** grass clumps, the tree, the fog planes, the hills and the character are painted billboards placed at real depths.
- **Result:** a camera move produces genuine parallax, not a zoom on a flat picture.

### Depth of field (`src/engine/DepthStack.tsx`)
- **Sorting:** drawables are sorted far → near.
- **Grouping:** consecutive drawables that share a quantised blur radius go onto one full-frame SVG plane with a CSS blur.
- **Blur radius:** `aperture × |1/d − 1/focus|`, so a rack focus re-blurs every layer by its real distance from the lens.

### Character system (`src/character/`)
- **`spec.ts`** is the **master lock**: landmark heights, proportions, wardrobe and colours. Every view is drawn from it.
- **`Walker34.tsx`** is the hero rig: three-quarter front, used in Scenes 01–03. It has:
  - breath, head turn/pitch/tilt, gaze, blinks, brows, lids and mouth;
  - art-directed elbow and wrist keys per pose, because 2D IK can't foreshorten a forearm pointing at the lens;
  - coat-hem and hair wind;
  - the map-unfold choreography.
- **`WalkerBack.tsx`** is the back-view walking rig: a procedural stride cycle with stance/swing legs, heel lift, pelvis bob and sway, counter-rotating shoulders, arm swing and coat swing.
- **`SheetViews.tsx`** holds the front and side turnaround views.
- **`Hands.tsx`** has the shared hand shapes (relaxed, grip, grip split for behind/in front of the paper) and the folded map packet.
- **`Lighting.tsx`** lights any view without changing the drawing. The view is re-rendered as a white/black silhouette mask to produce:
  - a rim of dawn light on the lit edge;
  - a cool fill band on the shadow side;
  - atmospheric haze;
  - a painted brush-surface texture.
- **Consistency guarantee:** every shot renders **the same component with the same paths**, only scaled and posed. The character cannot be redesigned or regenerated between scenes.

### The map (`src/props/PaperMap.tsx`)
- The pictorial map art is computed from the imagined world's camera projection (`worlds/imagined.ts → mapArtGeometry`). So in Scene 03 the ink route, hills and tree glyph sit exactly on the real path, hills and tree at the match frame.
- Folding is a 3 × 2 panel system with hinge-continuous transforms (accordion columns + bottom row).

### Transitions
- **Mist pass** (`post/Grade.tsx → MistPass`): hides the cut from Scene 01 to Scene 02 and carries the return to the present.
- **Watercolour reveal** (`scenes/Scene03.tsx → MapDissolve`): an SVG mask on the paper. The route is stroked with a growing width, then run through `feTurbulence` + `feDisplacementMap` + blur, with a pigment bloom at the edge.

### Grade (`post/Grade.tsx → Graded`)
- Desaturation and contrast.
- A soft-light temperature wash (cool present → warm imagined).
- Lifted blacks and a vignette.
- Animated film grain.

## Running it

```bash
cd deeply-rooted
npm install
npm run studio                 # interactive timeline / scrubbing at http://localhost:3000
npm run render                 # out/phase01_combined.mp4
npm run render:scenes          # out/scene01.mp4, scene02.mp4, scene03.mp4
npm run still:sheet            # out/character_reference_sheet.png (2880×1620)
npm run textures               # regenerate the texture library (needs python3 + numpy + Pillow)
```

On a machine without the cloud box's Chromium, Remotion downloads its own headless browser on first render. Rendering runs at about 1 frame per second with 4 workers, so the 41 s film takes ~20 min. Scene compositions render slices of the *same* timeline, so a scene preview is frame-identical to the combined cut.

## Central controls (`src/config/production.ts`)

| Control | Where |
|---|---|
| Scene durations / starts | `scenes` |
| Voiceover files, cue frames, word beats, enable | `voiceover` |
| Camera speed (global travel multiplier), lens, start/end positions, aperture | `camera.speed`, `camera.wide / medium / mapPush / imagined` |
| Character action timing | `character.s1 / s2 / s3`, `breathPeriod`, `blinks` |
| Fog density, haze, drift speed, return-mist peak | `fog` |
| Wind strength and speed (grass, coat, hair, leaves, paper) | `wind` |
| Lighting per world (sky, glow, ground, path, haze, rim, fill) | `lighting.present / imagined` |
| Transition timing | `transitions` |
| Palette | `config/palette.ts` |
| Grain, vignette, saturation, contrast, lift | `grade` |

## Limitations

1. **No AI image or video generation in this environment.** The art is hand-built vector and procedural painting. That gives a graphic, cut-paper painterly look rather than a fully rendered matte painting. A painted key-frame pass (with the prompts in `02_…md` and the reference sheet as the character reference) could raise texture fidelity. The rigs and timing here would carry over as the animatic.
2. **The character is a 2D cut-out rig.**
   - **Head turns:** limited to about ±20°. A larger turn would need additional drawn head angles.
   - **Faces:** deliberately simplified, and the painted shading planes are visible at close range.
   - **Hands:** simplified shapes with no individually animated fingers.
   - **Cloth:** the coat moves by authored sway, not cloth simulation.
3. **Walk cycle.** It's procedural and reads well at mid-distance, as used here. A close-up walk would need more drawn keys.
4. **Depth of field** is per-layer blur grouped by depth, a good approximation of a lens without bokeh shapes. There is **no motion blur**. Remotion's `<CameraMotionBlur>` could add it at roughly 5–10× render cost.
5. **Scene 02 → 03** uses a cut on action into the POV rather than one continuous camera move. The map faces him, so a continuous move from the medium shot would have to pass behind the paper.
6. **Fonts** on the reference sheet use the fonts installed here (Caladea / Inter). Other machines fall back to similar fonts.
7. **Licensing:** Remotion is free for individuals and companies of up to 3 people. Larger organisations need a Remotion company licence.
8. **Audio:** none is rendered yet, by design. The narration tracks are wired but disabled until the recordings exist.
