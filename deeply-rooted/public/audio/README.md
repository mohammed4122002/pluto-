# Narration goes here

Place the narrator's recorded lines here, then set `voiceover.enabled = true` in
`src/config/production.ts`:

- `VO01_have_you_ever_looked.wav`
- `VO02_not_because.wav`
- `VO03_you_had_plans.wav`

48 kHz / 24-bit WAV, one line per file, ~0.3 s of room tone before and after.
No AI voice, music or sound effects are used in Phase 01.
