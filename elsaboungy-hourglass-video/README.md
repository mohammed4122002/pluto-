# إعلان الساعة الرملية — الصابونجي (Remotion)

فيديو رأسي **1080×1920 ‏/ 30fps ‏/ 25 ثانية** بأسلوب **Premium Cartoon Advertising Motion Graphics** (2.5D لامع، ظلال ناعمة، بدون 3D واقعي).
المرحلة الأولى: الصورة كاملة **بدون تعليق صوتي وبدون موسيقى**. مسار الصوت جاهز للمرحلة الثانية.

## المعاينة

```bash
npm install
```

```bash
npm run studio
```

افتح http://localhost:3000 واختر:
- `ElsaboungyHourglass` — الفيديو كامل (صامت).
- `ElsaboungyPreview5s` — ريل مراجعة 5 ثوانٍ (ثانية من كل مشهد).
- `ElsaboungyHourglassWithAudio` — نفس الصورة + الصوت المحدد في `src/config/audio.json`.

## التصدير

```bash
npm run render
```
→ `out/elsaboungy-hourglass-review-silent.mp4` (H.264، CRF 16، صامت).

```bash
npm run preview5s
```
→ `out/elsaboungy-preview-5s.mp4`

```bash
npm run stills
```
→ صور مراجعة + `out/stills/contact-sheet.jpg`.

## التعديل بدون لمس الكود

| الملف | ماذا يتحكم |
|---|---|
| `src/config/timeline.json` | ترتيب المشاهد، **مدة كل مشهد بالثواني**، النصوص، نوع وطول كل انتقال، جملة التعليق الصوتي. المدة الكلية = مجموع المشاهد. |
| `src/config/brand.json` | اللوجو، الشعار، الموقع، رقم الواتساب، المدينة، الألوان. |
| `src/config/audio.json` | مسارات التعليق الصوتي والموسيقى (المرحلة الثانية). |

المشاهد القديمة (`hook`, `flow`, `burst`, `shine`, `brand`) ما زالت موجودة ويمكن إضافتها في `timeline.json` بالـ id.

## اللوجو الأصلي

ضع ملف اللوجو في `public/brand/` (مثلًا `logo.png`) واكتب في `brand.json`:
`"logo": { "src": "brand/logo.png", ... }`.
يُعرض دائمًا بـ `object-fit: contain` داخل صندوق ثابت، فلا يتمدد ولا يتشوه. حتى يتم ذلك يظهر شعار مؤقت مكتوب عليه **LOGO PLACEHOLDER**.

## التعليق الصوتي (المرحلة الثانية)

1. `npm run vo:guide` يُنشئ `voiceover/VO_SCRIPT.md` و`voiceover/vo-timing.srt` بالتوقيتات الدقيقة لكل جملة.
2. ضع التسجيل في `public/audio/voiceover/` (ملف واحد أو ملف لكل مشهد) وحدد المسار في `src/config/audio.json`.
3. `npm run render:vo` → `out/elsaboungy-hourglass-with-audio.mp4`.
