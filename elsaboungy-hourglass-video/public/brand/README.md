Drop the ORIGINAL Elsaboungy logo here (PNG with transparency or SVG), e.g. `logo.png`,
then set `"logo": { "src": "brand/logo.png", ... }` in `src/config/brand.json`.

The logo is drawn with object-fit: contain inside a fixed box (widthPx × heightPx), so it is never stretched,
cropped or recoloured. Until a file is set, a labelled "LOGO PLACEHOLDER" wordmark is shown.
